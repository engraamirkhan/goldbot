- Multi-instrument demo, lane L3 (engine), ADR 0074: one engine per account, one SymbolBook per instrument (`goldbot/engine/books.py`). Engine attributes that belong to one instrument (bars, resamplers, ticks, cost and contract caches, open trades and order rows, exploration, session table, magic range, journal) are data descriptors on the active book; the RiskGate, the one AccountState, the kill switch, risk-period state, approvals and order sender stay the account's. The run loop takes the books in turn on one thread (`books.account_pass`, quotes batched by `QuoteFeed`/`ticks_many`), so the gate is serial; each book keeps its own copy of the instrument facts the gate reads (spread, quote age, staleness, market hours, blackout, Friday cut), and an entry is booked on the shared state right after its order went out (`books.book` -> `RiskGate.book`). Exposure is account-wide over every book (`account_open_risk`, `group_exposure`, `others_group_notional`; `group_notional` published, null when unknown). XAUUSD is the primary book built from EngineConfig as before: the four-day replay is pinned to main (`tests/test_mi_xauusd_replay_golden.py`). Safety fixes: every price sent (stop, target, trail, orphan stop, BXR trail, pyramid stop) is rounded to the instrument's digits (`EngineConfig.price_digits`/`point`); an unknown contract size refuses entries (`contract_unknown`), never 100 oz. Magic: `3_000_000 + account_idx*10_000 + block*100 + offset`, gold keeps its base (`engine/magic.py`). Non-gold rows go to the store as (source=account, symbol=store_symbol) and order rows to `state/books/<account>/orders_<store>.json`; lot and swap terms per (account, symbol) live in `state/instruments.db` (SQLite WAL); unreadable or missing terms, an unconvertible swap or no `max_spread_points` refuse that book's entries while its exits run. Only demo accounts get non-gold books, and only ATR-scaled random controls run there (`<arm>@<instrument>`). Key levels (#306 follow-ups): the pull lock keys on the account's `box` or the tunnel port behind a loopback URL, and a hole the broker has no bars for is not re-read before HEAD_RECHECK. runner.py moves: the closed-trade record to `engine/closed_record.py`.
