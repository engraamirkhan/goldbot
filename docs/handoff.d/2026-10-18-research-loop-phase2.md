Loop budget path: a trial run with `--rule-ref loop` (`registry.LOOP_RULE_REF`) is charged per run against `research.loop_trials_per_run` (`generator.loop_refusal`: at most that many jobs, no config already in the registry, no retired/screening family, no config a pre-registration queued, never holdout scoring or discovery), NOT against `trial_budget_quarter` (`quarter_trials` skips loop rows; `trial_budget_overrides`/`budget_for` untouched for hand-dispatched trials).
