- **140. Autonomous discovery phase 1: spec DSL, search ledger, explore-window evaluator, family-combination generator.** Value: the first stage of the owner's 2026-10-28 directive ("devise novel new strategies that will just work and profit"; ADR 0058, `docs/research/autonomous-discovery-2026-10-28.md` section 8). It generates and screens strategy specs on 2010-2017 only, counts each one in K before it is evaluated, and calibrates against a random-side null. It spends no budget, writes no confirm read and adds no arm. New: `goldbot/research/autodisc/` (`spec.py`, `primitives.py`, `windows.py`, `outcomes.py`, `evaluate.py`, `ledger.py`, `novelty.py`, `nulls.py`, `gen_combine.py`), `scripts/autodisc.py`, `tests/research/autodisc/`. Edited: `goldbot/config.py` and `config/settings.yaml` (the `research.autodisc` block), `.gitignore`. Not touched: risk, engine, execution, accounts, exploration arms. Acceptance: (1) parity with `screen.py` on 3 families (tsmom 4h, box_break_close 15m, session_open 15m): event counts within 1%, net mean R within 0.01 R; (2) the window guard refuses any bar at or after 2018-01-01 (test); (3) a ledger row is written before each result, the hash chain verifies, and K_search counts distinct canonical hashes; (4) G0 runs 20 null replications, an injected +0.15 R edge is flagged, and <= 5% of pure-noise runs produce a survivor; (5) an existing arm re-expressed as a spec is labelled a variant; (6) 10k specs run in <= 30 min on the Mac at 10 workers (measured); (7) the report holds no 2018+ number (test); (8) ruff, mypy and the touched tests are green, and quant review is passed.
